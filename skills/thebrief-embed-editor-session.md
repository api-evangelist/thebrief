# Embed The Brief editor in your own product

This is The Brief's white-label surface: the full Ad Studio / GenStudio editor, hosted by The
Brief, opened as an *impersonated* session on behalf of one of your team's users. There is no
component library to install — the whole integration is a signed JWT and a URL.

## 1. Mint the session token

Sign a payload with the **API client secret** from Manage account > API credentials:

```javascript
import jwt from 'jsonwebtoken';

const token = jwt.sign({
  clientId,                 // required — the public clientId from API credentials
  userId,                   // required — the team user this session impersonates
  action: {                 // required — what the session exists to do
    type: 'create_blank_design',
    sizes: [{ width: 300, height: 250 }],
    projectId: 100,
    folderId: 111,          // optional
    editorMode: 'adstudio'  // 'adstudio' | 'genstudio'
  },
  sessionConfig: { /* step 3 */ }
}, secret);
```

The four published action types are `create_blank_design`, `create_design_from_template`,
`edit_design` (both take the design/template `hash`) and `get_share_link`.

**This token is a bearer credential that impersonates a real user.** A pair generated by a team
owner or admin can impersonate *any* user on the team. Mint it server-side, scope it to one
session, and never expose the secret to a browser.

## 2. Open the session

- Full page: `https://app.thebrief.ai/tokenAuth?token=<jwt>`
- Iframe: `https://app-proxy.thebrief.ai/tokenAuth?token=<jwt>`

Use `app-proxy` for framing — that subdomain exists specifically to be embedded.

```html
<iframe title="The Brief"
        src="https://app-proxy.thebrief.ai/tokenAuth?token=<token>"
        style="width:100%;border:none;min-height:800px"></iframe>
```

## 3. Restrict the session with `sessionConfig`

Every property is optional and applies only to this session:

`useDownload`, `useShareButton`, `useShareLinkComments`, `useAiEditText`, `useAiEditImage`,
`useAiTranslate`, `useAdServing`, `usePublishToMeta`, `usePublishToGoogleAds`, `brandkitIds`.

Toolbar control uses `hideToolbarItems` **or** `hideAllToolbarItemsExcept` — the two are mutually
exclusive and supplying both makes the session fail to load its configuration. Valid items:
`templates`, `elements`, `brandKit`, `layers`, `slides`, `animator`, `feedTool`, `apps`, `resize`,
`help`. An empty array changes nothing.

`brandkitIds` limits which brand kits appear; omit it and visibility falls back to team- and
project-level brand control.

Do not rely on the documented defaults — The Brief's own properties table and prose disagree on the
AI toggles. Set every toggle you care about explicitly.

## 4. Track the session boundary

The iframe posts two messages to the parent window. Check the origin before trusting them:

```javascript
window.addEventListener('message', (event) => {
  if (event.origin !== 'https://app-proxy.thebrief.ai') return;
  // { type: 'sessionStarted', sessionId, initToken }
  // { type: 'sessionEnded',   sessionId }
});
```

`sessionEnded` fires when the user clicks "End session" — that is your cue to reconcile: query the
API for the designs produced during the session (`designs` with `apiGenerated`, filtered by
`projectId`/`folderId`) rather than trusting the client message for state.

## 5. Combine with the Public API

App Integration is a UI surface, not a data surface. The pattern the docs recommend is to pair it
with the Public API: create the project and brand kit over REST/GraphQL, hand the user an editor
session scoped to them, then read the resulting designs back through
`GET /v1/designs?apiGenerated=true`.

See `components/thebrief-components.yml` for the full configuration reference and
`authentication/thebrief-authentication.yml` for the token model.
